The Android app made for liseur-sync

Liseur is an open-source ebook reader and the main app liseur-sync supports. Your books, your place in them, your highlights and your reading time follow you between the phone and your other devices.

Google Play F-Droid GitHub releases

Free, no ads and no account. It also works with calibre-web, Komga, BookOrbit and any OPDS catalog.

How it connects

Liseur needs your server's address and your account. You type them once.

  1. Install Liseur

    From Google Play, F-Droid or the GitHub releases.

  2. Open Settings, then Book server

    Choose liseur-sync as the kind of server.

  3. Enter the address, your username and password

    Tap Connect. Liseur uses the password once to ask the server for a device token with the permissions it needs, then drops it. Only the token stays on the phone.

If you would rather not type a password, make a token on the Apps tab of the server's Devices page and paste it in instead. Either way you can revoke it there at any time.

Use an https address. Plain http for a server on your home network works only if the server's owner has allowed it.

What works with liseur-sync

Liseur uses nearly everything the server offers. These are the parts you will notice.

Your whole library, in series

Browse and search the server's books. Series are stacked in reading order, with the volumes you are missing marked. Download one book, or fill the shelf with all of them.

A book's page shows what the server knows about it: subtitle, description, publisher, date, contributors with their roles, subjects, languages and identifiers.

Your place, down to the sentence

Positions use full reading locators, so a sentence on the phone is the same place in the web reader or on another device. The server keeps a log of positions, and a retry after a bad connection never creates a second copy.

Highlights, notes and bookmarks

Recolour a highlight, add a note to it or delete it, and the change reaches your other devices as a change to that same highlight, not as another copy.

Reading statistics from every device

Time read, day streak, sittings and pace, added up across every device the server knows about, for the last 30 days or another range.

needs the read-insights permission

Send books from the phone

A book that is only on the phone can be sent to a folder on the server that accepts uploads. Books in those folders can be deleted from the server too.

library-upload and library-delete

Translations shared between devices

Sentences translated as you read are cached on the server for your account. A second device reading the same book pulls them instead of calling the translation service again.

The sentence itself never leaves the phone. The server gets a hash of it and the translation.

And the app itself

Liseur draws books with the Readium engine and has light, sepia, dark and low-light themes, adjustable type and margins, a dictionary, read aloud with your device's voices, home-screen widgets and a reading companion that answers questions about characters from the pages you have already read.

Its own code has no ads, trackers or analytics. The repository has the full list, and the privacy policy says which services it talks to.
